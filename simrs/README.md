# SIMRS — RS Permata Medika (Group 7)

Implementation progress for the SIMRS project. This folder contains a PHP prototype for the Emergency Department, Radiology, and Registration/Scheduling interfaces.

## Run locally with XAMPP
1. Copy the `simrs` folder into XAMPP's `htdocs` directory.
2. Start Apache in XAMPP.
3. Open `http://localhost/simrs/login.php` in a browser.
